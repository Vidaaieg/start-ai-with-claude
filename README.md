> 💡 انسخ الـ Prompt زي ما هو، وغيّر بس الحاجات اللي بين `[ ]`.

## 📝 املا بياناتك الأول (مرة واحدة بس)

كل الـ Prompts اللي تحت بتستخدم نفس الخانات دي — املاها مرة وانسخها في أي Prompt.

| الخانة | تكتب فيها إيه | مثال |
|---|---|---|
| `[YOUR NAME]` | اسمك | Ahmed |
| `[CONTENT TYPE]` | شغلك أو مجالك أو نوع البيزنس | Online clothing store |
| `[AUDIENCE]` | مين الناس اللي بتشتغل معاهم أو بتكلمهم | Young women in Egypt 18–30 |
| `[LANGUAGE]` | اللغة اللي عايز الرد بيها | Egyptian Arabic |
| `[YOUR GOAL]` | عايز توصل لإيه بالـ AI | Automate customer replies and make my own content |
| `[SKILL LEVEL]` | مستواك دلوقتي | Complete beginner, no coding |
| `[HOURS PER DAY]` | وقتك المتاح يوميًا | 1 hour |
| `[TOPIC]` | الموضوع اللي عايز تتعلمه | AI Agents |
| `[DESIGN TYPE]` | عايز تصمم إيه | Instagram post / Landing page / Slide deck |
| `[YOUR TEXT]` | الرسالة أو الكلام اللي عايزه في التصميم | 20% off all summer dresses this week |
| `[REPEATED TASK]` | مهمة بتكررها كل يوم | Replying to the same customer questions on WhatsApp |

### ⚡ Prompt واحد شامل — املا والصق

املا الخانات والصق ده في Claude Chat — هيعملك خطة البداية كاملة.

```
Here are my details:
- Name: [YOUR NAME]
- Work / niche: [CONTENT TYPE]
- Audience: [AUDIENCE]
- Goal with AI: [YOUR GOAL]
- Current level: [SKILL LEVEL]
- Time available: [HOURS PER DAY] per day
- Reply in: [LANGUAGE]

I want to start learning AI using Claude. Claude has four parts: Chat, Cowork, Design, and Code.

1. In one short line each, explain what each part is and how it could help MY work specifically.
2. Tell me which part to start with and why, based on my level and goal.
3. Build me a 14-day learning plan that fits my daily time. For each day give: the task, which Claude part to use, the exact prompt I should paste, and what I should have at the end of the day.
4. Start simple (Chat) and move to the more advanced parts only when I'm ready.
5. Finish with the 3 most common beginner mistakes to avoid.

Keep it practical, no theory. Use simple words.
```

**بيعمل إيه؟** بيفهم إنت مين وعايز إيه، ويعملك خطة 14 يوم مفصّلة على مقاسك، كل يوم فيه الـ Prompt اللي تكتبه بالظبط.

## 💬 الـ Prompts خطوة بخطوة

## 🧭 1. خلّي Claude يعرفك (ابدأ بيه)

أول حاجة تعملها — عشان كل ردوده بعد كده تبقى على مقاسك.

```
I'm [YOUR NAME]. I work in [CONTENT TYPE] and my audience is [AUDIENCE].
My goal with AI is: [YOUR GOAL]. My level: [SKILL LEVEL].

Ask me 5 short questions to understand my work better, one at a time.
After I answer, give me the top 5 tasks in my work that AI can save me the most time on, ranked by impact, with how much time each could save per week.
Reply in [LANGUAGE].
```

**بيعمل إيه؟** بيسألك عن شغلك ويطلعلك أهم 5 حاجات الـ AI يوفرلك فيها وقت.
**نصيحة:** حط الكلام ده في **Project** عشان Claude يفتكره في كل محادثة جوه المشروع.

---

## 💬 2. Claude Chat — اتعلم أي حاجة بسرعة

```
Explain [TOPIC] to me like I'm a [SKILL LEVEL] working in [CONTENT TYPE].
Use one real example from my field.
Then give me a 3-question quiz to check I understood. Wait for my answers before correcting me.
Reply in [LANGUAGE].
```

**بيعمل إيه؟** بيشرحلك أي موضوع بأمثلة من شغلك، وبعدين يختبرك.
**نصيحة:** غيّر `[TOPIC]` لأي حاجة: Automation، n8n، Prompting، AI Agents…

---

## ✍️ 3. Claude Chat — اكتبلي محتوى

```
I run [CONTENT TYPE] for [AUDIENCE].
Write 5 social media post ideas for this week. For each one give:
- A strong first-line hook
- The post body (max 80 words)
- A call to action
Tone: friendly and simple. Language: [LANGUAGE].
```

**بيعمل إيه؟** بيطلعلك 5 بوستات جاهزة بالـ Hook والـ CTA.

---

## 🗂️ 4. Claude Cowork — خلّيه يرتب ملفاتك

```
Look at the files in the folder I shared with you.
1. List what's there, grouped by type and topic.
2. Suggest a clean folder structure for [CONTENT TYPE].
3. Show me the plan first. Do NOT move, rename, or delete anything until I approve.
Reply in [LANGUAGE].
```

**بيعمل إيه؟** بيشوف ملفاتك ويقترح ترتيب نضيف — من غير ما يلمس حاجة غير لما توافق.
**نصيحة:** دايمًا خليه يعرضلك الخطة الأول قبل ما ينفّذ.

---

## 📊 5. Claude Cowork — تقرير من ملفاتك

```
Use the files I shared (sales sheets, notes, or reports) and create a one-page summary for [CONTENT TYPE]:
- Top 3 numbers that matter
- What went well and what didn't
- 3 actions for next week
Create it as a new file. Do NOT edit or delete the original files.
Reply in [LANGUAGE].
```

**بيعمل إيه؟** بيقرا ملفاتك ويطلعلك تقرير صفحة واحدة فيه الأرقام المهمة والخطوات الجاية.

---

## 🎨 6. Claude Design — صمّملي بوست أو صفحة

```
Design a [DESIGN TYPE] for [CONTENT TYPE].
Audience: [AUDIENCE].
Main message: [YOUR TEXT]
Style: clean, modern, easy to read on mobile.
Give me 3 different versions so I can pick one.
Text on the design in [LANGUAGE].
```

**بيعمل إيه؟** بيعملك 3 تصميمات مختلفة من مجرد وصف بالكلام، وتختار وتعدّل عليها.
**نصيحة:** لو عندك ألوان أو لوجو البراند، ارفعهم وقوله يمشي عليهم.

---

## 💻 7. Claude Code — ابني أول حاجة بإيدك (حتى لو مش مبرمج)

```
I'm a [SKILL LEVEL]. Build me a simple one-page website for [CONTENT TYPE] targeting [AUDIENCE].
It should have: a header, a short about section, 3 services or products, and a WhatsApp contact button.
Explain every step in simple words as you go, and tell me exactly how to open it in my browser.
Page text in [LANGUAGE].
```

**بيعمل إيه؟** بيبنيلك موقع صفحة واحدة ويشرحلك كل خطوة ببساطة.

---

## ⚙️ 8. Claude Code — أول Automation ليك

```
I want to automate this task in my work: [REPEATED TASK].
1. Explain in simple words how it could be automated.
2. Suggest the simplest way to do it for a [SKILL LEVEL].
3. Build it step by step. Before anything that sends messages, deletes data, or costs money, stop and ask me first.
Reply in [LANGUAGE].
```

**بيعمل إيه؟** بياخد مهمة بتكررها كل يوم ويحولها لـ Automation — وبيستأذنك قبل أي حاجة حساسة.

---

## 🇪🇬 تقدر تكتبله بالمصري كمان

```
أنا [اسمك] وبشتغل في [مجالك]. عايز أبدأ أتعلم AI بـ Claude ومعنديش أي خبرة.
قولّي أبدأ بإيه بالظبط، واعملّي خطة أسبوع، كل يوم فيها حاجة واحدة أعملها في ساعة،
ومعاها الـ Prompt اللي أكتبه. اتكلم معايا بالمصري وببساطة.
```

## ⚠️ نصايح مهمة

- 🛑 **أي حاجة بتبعت أو بتمسح أو بتغيّر:** قول لـ Claude يعرضها عليك الأول (Draft بس) قبل ما ينفّذ.
- 👀 **راجع الشغل دايمًا** — الـ AI ممكن يغلط، وإنت المسؤول عن الناتج النهائي.
- 🎯 **كل ما تكون محدد أكتر، النتيجة تبقى أحسن** — قول مجالك وجمهورك وعايز الشكل إزاي.
- 🔐 **متحطش باسووردات أو أرقام كروت** في أي محادثة.
- 🐢 **ابدأ بالـ Chat** وبعدين انقل للأجزاء التانية — متحاولش تتعلم كله في يوم.
